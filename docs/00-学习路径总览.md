# OpenCode Agent 工程学习路径总览

这组文档的目标不是“介绍一个 CLI 工具”，而是把 `opencode` 当作一个可落地的 Agent 系统样本来拆开，帮助你从架构、模型、工具、上下文、时序、权限、记忆、子代理、自动压缩等角度，系统学习 AI Agent 的原理与工程实现。

这次版本已经把重点上调到“资深 Agent 工程师 / 大厂系统设计面试”层级，尤其强调：

- 难点问题
- 复杂问题
- 经典设计题
- 失败模式
- 并发与一致性
- 成本与评测
- 运行时边界与治理

## 这套文档回答什么问题

围绕 `opencode`，这套材料重点回答 6 类问题：

1. 一个终端 Agent 系统到底由哪些模块组成？
2. 模型、Provider、Prompt、Tool、Session、Permission、TUI 之间如何协作？
3. 为什么 Agent 不只是“一个大模型 + 一个 prompt”？
4. 多模型、多角色、多轮工具调用、子代理是如何落地的？
5. 工程上如何做权限控制、上下文管理、记忆压缩、失败恢复与成本统计？
6. 如果要站在 Google 级别 Agent 工程面试和架构评审的视角，该追问哪些真正困难的问题？

## 建议学习方法

- 第一遍先看图，不纠结细节。
- 第二遍把文档中的 Mermaid 图和源码目录一一对照。
- 第三遍重点看 [01-系统架构总览](./01-系统架构总览.md) 和 [03-模块调用流程与时序图](./03-模块调用流程与时序图.md) 里的“面试官追问”和“设计取舍”部分，不要只停留在流程理解。
- 第四遍重点看 [04-AI-Agent-50问](./04-AI-Agent-50问.md)，把里面的问题当成系统设计面试题，不要只背答案，要自己先答一遍。
- 第五遍再看 [05-工程实践与进阶建议](./05-工程实践与进阶建议.md)，把它当成“如果我要把这个系统做成更强的生产级 Agent，我会先补什么”的路线图。
- 第六遍用 [06-Google-面试模拟题](./06-Google-面试模拟题.md) 做真正的口头演练，按题目、追问、结构化答法来练。

## 一句话总论

`opencode` 本质上是一个“以 Session 为边界、以 Agent 为编排器、以 Tool 为动作面、以 Provider 为模型适配层、以 Permission 为安全阀、以 TUI 为可视化外壳”的终端 Agent 框架。
